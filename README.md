# Tanzania Health Alliance Website

Modern, mobile-first React website for THA.

## Quick Start

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

Upload `dist/` folder to cPanel.

## Features
- Mobile-first responsive design
- Glass morphism header
- Smooth animations
- Clean navigation
- Contact forms
- Newsletter signup
- Resource library

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- React Router
- HashRouter (cPanel compatible)

## Pages
1. Home - Hero, stats, focus areas
2. About - Team, timeline, mission
3. Make a Difference - Volunteer, donate, partner
4. Academy - Health resources
5. News - Latest updates
6. Contact - Form, location

## Deploy to cPanel
1. Build: `npm run build`
2. Upload `dist/` contents to public_html
3. Upload `.htaccess` file
4. Done!
